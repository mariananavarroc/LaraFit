## 📖 Acerca del Proyecto

LaraFit Studio es un gimnasio exclusivo para mujeres ubicado en Cd. [cite_start]Victoria, Tamaulipas[cite: 4, 8]. [cite_start]Actualmente administra su operación diaria de forma manual[cite: 4]. [cite_start]Este proyecto propone una **aplicación web administrativa** optimizada para usarse desde un iPad[cite: 6]. 

[cite_start]El objetivo es gestionar de manera centralizada y segura el registro de alumnas, asistencias, pagos, cupos por horario y reportes [cite: 37][cite_start], mejorando la eficiencia y fortaleciendo la experiencia en un espacio diseñado para brindar confianza a las mujeres[cite: 6].

---

## ✨ Características y Módulos

El sistema está diseñado para resolver las necesidades operativas diarias mediante los siguientes módulos:

* [cite_start]**👩‍🦰 Gestión de Alumnas:** Registro seguro, actualización y consulta de datos personales y contactos de emergencia[cite: 40].
* [cite_start]**📅 Horarios y Cupos:** Configuración de clases, validación para evitar sobrecupos y visualización de disponibilidad en tiempo real[cite: 43].
* [cite_start]**✅ Control de Asistencias:** Registro rápido y ágil de asistencias diarias e historial por alumna[cite: 41, 83].
* [cite_start]**💳 Gestión de Pagos:** Registro de mensualidades, cálculo automático de vencimientos y filtro de alumnas con adeudo[cite: 42, 86].
* [cite_start]**📊 Reportes:** Métricas clave como alumnas activas, ingresos por periodo y horarios con mayor demanda[cite: 44, 85].
